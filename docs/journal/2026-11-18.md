  - 다른 경로로 보존하지 않는다 — `config.rs:62-69` `load`는 파일만 읽고, `apply_lang`(72-83행)은 값이 `auto`이거나 모르는 값일 때만 OS UI 언어로 해석한다. 별도 파일·레지스트리 없음. `save`(86-94행)는 `s.to_ini()`를 그대로 쓴다.
  - 설정 창은 값을 정확히 넣는다 — `settingswnd.rs:717` `s.lang = get_lang_combo(…)` → 730행 `config::save` → 여기서 사라진다.

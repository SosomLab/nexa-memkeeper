## 직전(2026-08-07 11차) — M4 설정 완료

- **단계: M0~M4 구현 완료 — 실기 QA 후 `0.5.0` 승격, 다음은 M4-2(핫키)·M5(배포).**
- **설정**: 트레이 우클릭 → [설정…] 창(자동 정리·정리 영역·일반, [기본값] 포함). 저장 시 `data\settings.ini`(폴백 `%LOCALAPPDATA%`)에 쓰고 상주 셸이 **즉시 반영**.
- **자동 정리 동작**: 사용률 ≥ 임계값(기본 90%)이고 쿨다운(기본 5분) 경과 시 자동 실행 + 주기 정리 옵션.
- **정리 영역 ③④⑤ 구현**(⑥은 M5). 설정에서 끈 영역은 실행하지 않음 — 실측 확인(①만 켜면 트림만 461건, ②③만 켜면 퍼지만).
- 앱 매니페스트 추가(공용 컨트롤 v6·asInvoker). DPI 인식은 레이아웃 비례화(M3-4) 후로 보류.
- **시간 단위 ms 통일**(18차): `poll_ms`·`cooldown_ms`·`interval_ms`·`list_refresh_ms` — 구 키(초·분)는 읽어서 자동 환산 후 새 키로 저장(1회 마이그레이션, 실기 확인).
- QA 반영(19차): 설정 창 라벨이 2줄로 접히던 문제 — 라벨/입력 규격 통일(218/232/96), 실제 텍스트 폭 실측으로 확인(최대 173px < 218px).
- 실측: exe **0.51MB** ≤3 · 상주 RSS **1.32MB** ≤5 · 테스트 **38 green**.
- **다음**: M4-2(전역 핫키) → M5(배포 2채널 — 설치형 Inno + 포터블 ZIP). 실기 QA 통과 시 `0.5.0` 승격.
